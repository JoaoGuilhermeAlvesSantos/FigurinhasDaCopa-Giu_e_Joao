Instruções

Use esta página para transformar uma lista de figurinhas encontradas em um novo arquivo data.js.

  • Cole dados como ✅ KOR20, ✅ CAN16, ✅ CUW9.
  • O parser ignora cabeçalhos com # e linhas vazias.
  • Clique em Processar input para gerar o conteúdo.
  • Clique em Salvar data.js para gravar o arquivo diretamente, se o navegador permitir.
  • Clique em Baixar data.js como fallback se a gravação direta não estiver disponível.
